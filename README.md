# MindCare 👋

**MindCare** là siêu ứng dụng đồng hành tâm lý dành cho sinh viên, giúp quản lý cảm xúc, nhận hỗ trợ tâm lý, chat với AI và nhiều tính năng hữu ích khác.

Dự án được tạo bằng [Expo](https://expo.dev) thông qua [`create-expo-app`](https://www.npmjs.com/package/create-expo-app).

Cài đặt các phụ thuộc:

```bash
npm install
```

Khởi chạy ứng dụng:

```bash
npx expo start
```

Ứng dụng có thể chạy trên:

- Development build
- Trình giả lập Android hoặc iOS
- [Expo Go](https://expo.dev/go)

Chỉnh sửa các file trong thư mục **app**. Dự án sử dụng [file-based routing](https://docs.expo.dev/router/introduction/).
